# Practices

* [Answer one question with a proof of concept](practices/one-question-poc.md) - Write one yes-or-no question first, fake everything else, and end with a decision.
* [Brief agents like a team](practices/brief-agents-like-a-team.md) - Give agents a written goal, the context they cannot guess, a check to pass, and a human review.
* [Evaluate agents on real tasks](practices/evaluate-agents-on-real-tasks.md) - Grade real tasks with code first, rerun on every change, and read the failures.
* [Plan for the device going away](practices/plan-for-device-going-away.md) - Hardware links drop, so every screen needs an answer and tests run on real devices.
