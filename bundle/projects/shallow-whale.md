# What it is

A crypto trading game: start with cash, buy and sell coins, and try to end up ahead. Prices come from a simulated market, or live from Binance or CoinGecko. Trades never touch an exchange.[^post]

# Facts

* No accounts, ads, analytics or purchases. Progress stays on the device.[^post]
* Only the built game is public, in the `shallow-whale/` folder of the [Personal site](personal-site.md) repository. None of the public repositories holds its source.

# Run it

Open <https://ilya-paskhover.github.io/shallow-whale/>. It can be installed as an app from the browser menu.[^post]
